# CoDZombies
Senior Capstone Project in which I made my own rendition of CoD Zombies

-------------
Video of gameplay:

https://www.youtube.com/watch?v=XcOBi9RKvok

-------------
Creating this game was a very long learning process because I had never used Unreal Engine to create my own game and had only used it for level design previously. Throughout the creation of this game, I had to learn everything that goes in to using Unreal such as all of the UProperty stuff to be able to keep track of different actors. Working on this project also made me much more familiar with using multiple files to keep everything separate and using include statements to make the files interact properly. I had done it before but had limited practice with projects that were done across multiple files.
